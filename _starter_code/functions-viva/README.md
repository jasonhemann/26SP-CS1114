This is a short, individual, in-person oral where I give you a written
problem (in the style of our ProblemSet 0 homework prompts) and ask
you design a solution at the board from scratch. No notes, no IDE, no
AI tools.

I want to verify that you can also whiteboard-code, without fancy
external tooling support, apply the full design recipe within a
reasonable time limit, and that you can explain your own code clearly.

If you want a high level overview of how vivas run in this course, see
[the general viva](../../viva.md) page.

# Format

8 to 10 minutes. I hand you a short problem description, you work it
at the board. You must carry out the full design recipe on the spot
and write a correct function that solves the stated problem. Expect
one quick follow-up question or a small variation of the prompt.

No laptops, tablets, phones, watches, or other electronics. Paper copy
of the prompt only. Dry erase markers provided.

# Grading

Score out of 10, based on three criteria:

- Design recipe execution (0-4): purpose and signature, examples and
  tests, a sensible plan, and an implementation that follows from it.
- Correctness and reasoning (0-4): function matches the prompt,
  handles typical inputs, and you can justify key steps or trace one
  test cleanly.
- Clarity and pace (0-2): readable boardwork, steady progress, clear
  verbal explanation.

# Redo policy

One redo is allowed during the posted redo window, typically the
following week. Your recorded viva grade is the higher of the two
attempts. You should not expect the same prompt on a redo.
